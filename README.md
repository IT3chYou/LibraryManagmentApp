


# 📚 Next Generation Library & To-Do Application
# LibraryManagmentApp
Library &amp; TODO App Manage books, keep track of tasks, stay organized. 

A modern, user-friendly Library and To-Do management application built with **Python**, **Streamlit**, and **SQLite**.  
This application provides a clean interface for managing books and personal tasks with fast, efficient operations.

---

## 🚀 Features

### 📘 Library Module
- ➕ **Add Books** — Add new books with details such as title, author, category, etc.  
- ✏️ **Update Books** — Modify the information of existing books.  
- 🗑️ **Delete Books** — Remove books permanently from the library database.  
- 🔍 **Search & Filter** — Quickly locate books using dynamic search filters.  
- 📄 **Book Listing** — Display books in a well-structured, paginated table.

---

### 📝 To-Do Module
- ➕ **Add Task** — Create new tasks easily.  
- ✏️ **Update Task** — Edit task information.  
- 🗑️ **Delete Task** — Remove completed or unnecessary tasks.  
- 🎯 **Progress Tracking** — Track your daily workflow.
